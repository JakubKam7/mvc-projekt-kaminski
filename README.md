# mvc-Skarbonka-kaminski

Projekt zaliczeniowy - Programowanie aplikacji MVC
Autor: Jakub Kamiński, nr albumu: 163325

## Temat
Aplikacja „Skarbonka” to prosty rejestrator wydatków, który pozwala użytkownikom na bieżąco kontrolować swój budżet poprzez dodawanie nowych wpływów i wydatków za pomocą formularza. 
Strona główna wyświetla aktualny stan środków oraz historię operacji, ułatwiając codzienne zarządzanie domowymi finansami.

## Struktura Repozytorium
- czesc1-servlet-jsp - aplikacja Servlet + JSP + JSTL (Tomcat 10.1)
- czesc2-spring-boot - aplikacja Spring Boot + Thymeleaf
- docs - dokumentacja projektu
